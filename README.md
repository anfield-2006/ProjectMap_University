# ArriveWise

เว็บจัดสรรเวลาให้ไปถึงเป้าหมายทันเวลา: ถามกิจวัตร 3 ข้อ → คำนวณเวลาตื่น เวลาออกจากบ้าน และเวลาเผื่อรถติด/อุบัติเหตุ พร้อมเช็คลิสต์ นาฬิกาปลุก แจ้งเตือน 1/3/7 วัน และนำทาง Google Maps / GPS แบบเรียลไทม์

ธีม: ดำ 60% · ขาว 30% · น้ำเงิน 10%

## รันบนเครื่อง

```bash
uv venv .venv && uv pip install --python .venv/Scripts/python.exe -r requirements.txt   # ครั้งแรก
.venv/Scripts/python.exe server.py        # → http://127.0.0.1:5500
```

ถ้าไม่ได้ติดตั้ง PyThaiNLP เว็บยังใช้งานได้ โดยจะใช้ `Intl.Segmenter` ของเบราว์เซอร์ตัดคำแทน

## ทดสอบ

```bash
npm install
npm test            # unit tests: อัลกอริทึม + NLP
npm run test:e2e    # Playwright (ต้องรัน server ก่อน)
```

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `css/app.css` | หน้าเว็บ + ธีม |
| `js/engine.js` | อัลกอริทึมคำนวณทั้งหมด (pure functions) |

| `legacy/` | ไฟล์ UniRoute เดิมของ repo |

## อัลกอริทึม

1. **Backward scheduling**: นับย้อนจากเวลาเริ่มกิจกรรม → ถึงก่อน → เผื่อ → เดินทาง → ขั้นตอนเตรียมตัว → เวลาตื่น
2. **Traffic profile ตามวันและเวลา**: วันธรรมดา/วันหยุด ช่วงเช้า/เย็น แยกกัน และเน้นเช้าวันจันทร์กับเย็นวันศุกร์เป็นพิเศษ
3. **Trip-window integration + fixed-point solve**: คิดจราจรตลอดช่วงที่เดินทางจริง ไม่ได้ดูแค่จุดเวลาเดียว (เช่น จันทร์ 17:00 ใช้โปรไฟล์ช่วงเย็น ไม่ใช่ช่วงเช้า)
4. **Monte Carlo 4,000 รอบ**: จำลองเวลาเดินทางแบบ lognormal ร่วมกับการเกิดเหตุแบบ Poisson เพื่อหาเวลาเผื่อตาม P85/P95/P98 และโอกาสถึงทันเวลา
5. **EWMA learning**: เรียนรู้จากเวลาเดินทางจริงเมื่อผู้ใช้เช็ค “ออกเดินทาง” และ “ถึงที่หมาย”
6. **Sweep-line**: ตรวจกิจกรรมที่เวลาชนกัน
7. **Min-heap**: คิวแจ้งเตือนและนาฬิกาปลุก
8. **Greedy**: ถ้าช้ากว่าแผน จะแนะนำขั้นตอนที่ควรข้ามเพื่อให้ยังทัน
9. **Sleep cycle 90 นาที**: แนะนำเวลาเข้านอน
10. **Haversine**: คำนวณระยะทางสำรองเมื่อเรียก API เส้นทางไม่ได้

## Thai NLP (อ้างอิง nlpforthai.com/tasks)

ใช้ Word segmentation (PyThaiNLP newmm), POS tagging (orchid_ud) และ Named-entity แบบ rule-based (DATE/TIME/DURATION/PLACE) ร่วมกับ Text classification (lexicon) และ Text normalisation (เลขไทย คำตัวเลข และตัวย่ออย่าง ม.อ., รพ., มหาลัย)

## Google Maps (เวลาเดินทางที่รวมสภาพจราจร)

- **มี API key:** ใส่ไว้ในไฟล์ `.env` บรรทัด `GOOGLE_MAPS_API_KEY=...` (ดูตัวอย่างใน `.env.example` และต้องเปิดใช้ *Routes API*) จากนั้นรีสตาร์ต `server.py` ระบบจะดึงเวลาเดินทางจาก Google ตามเวลาที่จะออกจากบ้านจริงให้อัตโนมัติ
- **ไม่มี key:** ในหน้าเพิ่มกิจกรรม กด "ดูใน Google Maps" แล้วกรอกจำนวนนาทีที่ Google บอก ระบบจะใช้ค่านั้นแทนการประมาณ
- เวลาเผื่อถูกจำกัดไว้ไม่เกิน 30% ของเวลาเดินทาง (อยู่ระหว่าง 10–60 นาที) และถ้าระยะทางเกิน 80 กม. จะขึ้นเตือนว่าพิกัดอาจผิด

## หมายเหตุ

- เสียงปลุกและการแจ้งเตือนในเว็บทำงานเฉพาะตอนเปิดแท็บไว้ ถ้าต้องการให้มือถือปลุกแม้ปิดเว็บ ให้ใช้ **Export .ics**
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ และ `localhost` กับ `file://` แยกข้อมูลกัน
- แผนที่ใช้ OpenStreetMap และเส้นทางใช้ OSRM (ฟรี ไม่ต้องใช้ API key) ส่วนการนำทางจริงเปิดผ่านลิงก์ Google Maps
